# 跨系统汉化验收矩阵

每次扩展一个规则族，都检查菜单、正文、状态栏、通知、帮助与返回重绘；未触发的面不能标为通过。捕获命中不等于可见验收。

| 系统 | 已接入的面 | 本轮待实测与缺口 |
| --- | --- | --- |
| 物品 | 背包/拾取组合、手持栏、装备及地面发现通知；毛皮/鱼种/纺织长度；日志物品行 | 手持换物/双手、盾牌姿态、截短名、交易报价、容器 |
| 动作 | 方向选择共用入口的34标题与33段说明 | 开关门、攻击、推拉、投掷、取消；未知动作回退 |
| 地图 | 地形图标签、底栏地形与文化村落 | 地图悬浮、任务地点、区域标题；地名英文释义尚保留 |
| 交谈 | 菜单、结伴与反悔、动物买卖、贤者/铁匠问路与技能自述 | 本地/远方/未知/不同技能等级；武器技能另一路待接入 |
| 通知 | 整句匹配、物品组合、部分障碍物、颜色继承；消息总览旧记录翻译与分页 | 连续历史、分页、确认后缀、音效、长句、多目标；旧像素不追溯修复 |
| 人物状态 | 角色档案、护甲统计、人物穿戴/携带悬浮窗、部分基本状态标签 | 营养9级/体温13级/精力7级已接入，动态变化待用户检验 |
| 生产与交易 | 部分菜单及背包选择 | 配方条件、缺料、耗时、结果与失败通知、议价全过程 |
| F5课程 | 两套48任务、当前/完成正文、关联键和奖励说明 | 自动布局通过；待用户逐页检验，NPC任务另计 |
| 帮助与百科 | 帮助部分全文、两页超链接实测；新增22材料/工具主题待用户检验 | 全主题、滚动、长文、窗口变化 |

工作顺序：从原生生产函数枚举相关输出与调用面 → 形成有界语法/词表 → 原生匹配与未知回退测试 → 测试角色触发多个正反分支 → 返回/滚动/切换语言回归。不要用新词条数量代替这个矩阵。
