# 消息总览

按 `v` 打开消息总览。原生 `MsgLog()` 继续读取 `CharacterPath/msglog.txt`，处理上下滚动、整页翻阅和回车添加备注。中文绘制发生在读取之后。日志文件的原文、颜色和元数据沿用游戏格式。

在 3.89.1 x86_64 中，`logmsg` 把原始通知首字节保存在方括号中。例如 `(008000):16g8:[=]{04FF0214} | Your character has been saved.`。在 `MsgLog()` 调用 `SANATAULUKKO_Lisaa` 填充单条消息时，运行库根据这条记录在 `notebuf` 中的槽位读取对应的 `formatbuf`，再用 `=Your character has been saved.` 查找现有 `message` 词表和动态规则。纯物品名称和数量复用物品组合规则。手写备注的 `["]` 标记跳过查词。缺少翻译的记录继续由原生代码绘制。

绘制时先调用 `showtext_sanataulukko` 的原生测量模式来确定当前记录的行数，再将中文限制在这些行内，颜色取自原生绘制参数。中文优先按原宽度换行，超出原行数时压缩行宽，以保留完整文字和原生记录边界。页脚显示的记录序号由原生代码计算。
