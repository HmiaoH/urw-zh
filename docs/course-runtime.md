# F5 课程任务文字

适用版本为 UrW 3.89.1 macOS x86_64。地址为未加 ASLR slide 的虚拟地址。

`Tee_Gamecourse_1()`（`0x1001afce0`）和 `Tee_Gamecourse_2()`（`0x1001b1d60`）各构造 24 条任务记录。`Kirjoita_Tehtavatiedostoon`（`0x1001afb60`）每次向 `taskdata.urw` 写 2568 字节。提取时将受支持的可执行文件映射到隔离的 x86 进程，调用两个原生构造函数。写入函数被替换为向临时记录流复制内存，键命令函数被替换为记录命令编号。没有启动游戏，也没有写入角色数据。第一套课程的所有标题和段落字段与测试角色现有的原生记录相同。第二套课程的快捷键描述按第一套课程记录中的命令编号还原，独有的 T 命令在二进制中核对。

`Tehtavan_Kuvaus` 将各组四个片段依次送入 `SANATAULUKKO_Lisaa`。对空片段，后者在 `0x1001b9dd0` 插入两个 `<br>`。目录保留这些标签，并按现有 `paragraph` 匹配逻辑拼为整段。当前任务、完成段落、通用底部提示的绘制调用点分别为 `0x1001b446c`、`0x1001b4325`、`0x1001b47e7`。这些位置已经通过现有段落入口，正文可以直接使用 `paragraph` 词条。

`TehtavaNaytto` 读取任务列表并以 `%c.%s` 构造按钮（`0x1001b4b35`），`Piirra_Nappain` 分开绘制按键和标题。单键说明也经该按钮路径。以 `[` 开头的说明走 `buttext`。该函数用原生按键板绘制方括号内的键，在 `0x100150000` 绘制键之间的文字，在 `0x1001500af` 绘制后续说明。词条只翻译说明，原生按键和标签的显示保留。`or` 属于单独的按键连接词，需在 `showtext` 的返回地址 `0x100150005` 选择 `course-key-conjunction` 上下文。

当前、完成和通用底部段落均以 440 像素宽绘制。当前正文从 y=75 起，关联按键区从 y=235 起。完成正文从 y=80 起，标题框下缘约在 y=200。底部提示从 y=450 起，F5 按键提示在 y=555。现有中文段落行距为 12 像素。可用 `layoutParagraph` 检查最后一个实际绘制的文字行，保留末尾的空白标签。
