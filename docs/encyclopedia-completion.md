# 百科正文与交易拒收（2026-11-05）

## 范围与证据

本批按用户要求由三个 gpt-6-luna 子代理翻译百科原生绘制片段。三批共1956条候选，剔除65条图片文件名等资源元数据，合入1891条新正文片段。保留此前已审校正文后，对当前版本 GAME.NFO 的308个主题、2047个实际非空正文片段检查，均有审校译文。标题及底部预览同时按所有主题别名检查；网址和纯换行标记保留原样。

这不是整个游戏的汉化率，也不是实机通过率。当前批次未操作游戏，按用户约定由用户检验。正文逐片段源位置和覆盖详情见 `data/rules/encyclopedia_coverage.json`，可用 `python3 tools/audit_encyclopedia.py` 重算。

## 翻译与链接

草稿保存在 `data/drafts/encyclopedia_luna_1.json` 至 `_3.json`。初译中发现过跨行错位、重复语义及术语错误，已退回修订，并交叉抽审各主题首、中、尾；主代理复核后修正武器技能、陷阱路线、船篙说明等段落。elk统一为驼鹿，lippo为抄网。原文、行号和149字节片段边界保持可追溯。

`tools/compile_encyclopedia_review.py` 在人工审校后合并草稿，校验源片段、控制标签、完整链接目标及重复键，不负责自动翻译。输出为 `data/translations/encyclopedia_complete.json`，不覆盖已建立的上下文词条。所有译文只用于显示，不改GAME.NFO、物品标识及存档。

链接显示词与目标ID分离。新增对TIETÄJÄ等非ASCII目标的支持：链接目标转回原版CP437字节后比对主题表及写入点击目标；正文解码和底部主题预览也使用该资源编码。测试核对TIETÄJÄ的原生七字节序列，避免UTF-8导致跳转失效。链接几何继续由中文实际字宽生成，未知目标及越界仍沿用英文路径。

回归按308页原文次序组合布局，保留段落间隔，检查正文边界和最多99个链接区域的原生限制；底部摘要检查较窄栏位424像素宽。没有靠截断正文压入窗口。

## 交易拒收

逆向 `tradeacc(int,int,unsigned char)`（0x100180740—0x100181343），确认写入 `_tradeacc_rejreason` 的16个动态格式及1条固定回复。`npc_trade` 在0x100181e73将该缓冲区交给CrTalk，既有NPC绘制入口可接管，无需新挂钩。

覆盖：玩家自用物品、价值不被认可、不需要、搬不动/负重过高、数量过多、库存充足、食品储备充足、非玩家所有、品质不符、未知品种、在当前交易中价值过低，以及未鞣制毛皮。另覆盖只收北方鞣制上等毛皮的固定回复。

`src/trade_rejection.inc`只匹配完整原生句型，物品字段复用有界物品组合器；原生食品分类that/meat/fish/meat products/fish products使用显式映射。未知物品仍回退整句英文，不能把这项规则覆盖称作所有可能物品均已汉化。不会改变NPC接受物品的判断或物品价值。
